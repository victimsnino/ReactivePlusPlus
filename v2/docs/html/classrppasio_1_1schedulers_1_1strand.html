Detailed Description

Asio based scheduler where each worker is assigned an asio strand to execute schedulables with the guarantee that none of those schedulables will execute concurrently.

This scheduler can efficiently enable multi-threading execution when running provided io_context in multiple threads. Compared to the thread_pool scheduler, a worker is not pinned to a single thread and schedulables are instead dynamically dispatched to potentially different io_context threads depending on load.
